# Amir Shamaei

A minimal academic website for Amir Shamaei, biomedical researcher and machine learning engineer.

The site is intentionally small: one static HTML file, one stylesheet, a profile photo, and a social-preview image. It is responsive and deploys directly through GitHub Pages.

## Local preview

Open `index.html` in a browser, or run a local static server from this directory.

## Publishing

The GitHub Pages site is published from the `master` branch at [amirshamaei.github.io](https://amirshamaei.github.io).

## Structure

- `index.html` — page content and metadata
- `styles.css` — typography and responsive layout
- `profile.jpg` — profile portrait
- `og.png` — social sharing preview
- `sci_cv_assitant.tex` — source CV
